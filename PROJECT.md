# Playeras El Güero

Sitio web oficial de Playeras El Güero.

## Objetivo

Crear una plataforma profesional para mostrar diseños, recibir cotizaciones,
personalizar playeras y posteriormente vender productos en línea.

## Dominio

playeraselguero.com

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
- Git
- GitHub
